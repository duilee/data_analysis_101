# DAU 기여 추정 — power law 리텐션 적합

**챕터**: `05_이_기능은_DAU_얼마짜리_기능일까/` · 노트북: `dau_forecast.ipynb`

## 이 방법이 푸는 문제

신규 유저 리텐션 커브에 power law `y = a·x^b`를 적합해 모양 계수 `b`를 구하고,
`x^b`의 1년 누적합을 상수 하나로 접어 **`DAU 기여 = 신규 유저 수 × D1 리텐션 × 상수`**
공식을 만든다. 기능 하나·유입 캠페인 하나가 장기적으로 DAU 몇 명짜리인지 어림할 수 있다.

## 실행·검증

```bash
python generate_data.py      # data/active_daily.csv 생성
jupyter nbconvert --to notebook --execute --inplace dau_forecast.ipynb
```

- 입력: `data/active_daily.csv` (`date, user_id, platform, country_code, install_flag`).
- `sql/retention_curve.sql`(인라인 동일)이 basis_month × platform별 D1~D28 리텐션을 만든다.
- **기대 결과**: 생성기가 심은 정답은 ios `a=0.42, b=-0.45`, android `a=0.35, b=-0.50`.
  코호트 그룹별 `curve_fit` 결과의 `b`가 이 값 근처로 복원되고, 관측-모델 곡선이 겹쳐야 한다.
- 실습 2의 상수는 `baseline = 1.0 + np.sum(np.arange(1, 365) ** b_mean)`으로 계산된다.

### 3. 코드 치환 지도

노트북의 해당 셀을 읽고 아래만 바꾼다. 나머지 코드는 그대로 재사용한다.

| 앵커 (실습/식별자) | 무엇을 | 어떻게 |
| --- | --- | --- |
| 실습 1 `query` 셀 | `read_csv_auto('data/active_daily.csv')` | `YOUR_CSV_PATH`로. 컬럼명도 매핑대로 치환 |
| 〃 | `install_flag = TRUE` (신규 정의) | 독자의 신규 정의로 (없으면 `MIN(date)` 파생 CTE 추가) |
| 〃 ⚠ | `BETWEEN 1 AND 28` 관측 윈도 | 바꾸면 적합 셀의 `days = np.arange(1, 29)`도 **함께** 변경 |
| `b_mean` 계산 셀·플롯 셀 | `'ios'` / `'android'` 하드코딩 (적합 루프 자체는 groupby라 수정 불필요) | 독자의 세그먼트 값으로 (세그먼트 없으면 그룹 축 제거) |
| 실습 2 셀 | `np.arange(1, 365)` 기간 | 원하는 horizon으로 (기본 1년 유지 권장) |

- `func(x, a, b)`, `curve_fit(..., maxfev=10000)`, `df_constant`, `baseline` 계산 로직은
  건드리지 않는다. `p0` 초기값을 추가하지 말 것(기본값으로 수렴한다).
- `sql/retention_curve.sql`은 인라인 쿼리의 전시용 사본이다 — 노트북만 고치면 sql 파일은
  구버전으로 남는다는 점을 독자에게 알린다.

### 4. 단계별 진행

1. 치환한 `query` 실행 → 리텐션 테이블 출력. day_diff별로 단조 감소하는지 함께 확인.
2. 그룹별 `curve_fit` → `df_constant`(그룹별 `a`, `b`) 표 제시. 그룹 간 `b` 편차 확인 —
   편차가 크면(예: 0.1 이상) 상수를 하나로 접지 말고 세그먼트별 상수를 제안.
3. 관측 vs 모델 곡선 플롯 → 독자와 적합 품질 확인 (초반 급락·후반 꼬리가 맞는지).
4. `baseline` 계산 → 독자의 일 신규 유저 수·D1 리텐션을 물어 최종 DAU 기여 산출.

### 5. 결과 해석

- `b`가 0에 가까울수록(완만) 상수가 크다 = 신규 1명의 장기 DAU 가치가 크다.
- 공식은 "신규 유입을 늘리는" 액션과 "D1을 올리는" 액션과 "커브를 완만하게 하는" 액션의
  기대 효과를 각각 분리해 계산할 수 있게 해 준다 — 독자의 논의 중인 액션에 대입해 준다.
- D1~D28 관측으로 365일을 외삽한 값임을 항상 병기한다.

## 함정

- `curve_fit`에 `p0` 초기값을 하드코딩하지 말 것 — 기본값으로 충분히 수렴한다.
- power law는 초기 급락 후 완만한 감소 형태에 맞는 모델이다. 요일 효과로 리텐션이 오르내리면
  주 단위 평균으로 스무딩 후 적합한다.
- 장기 코호트가 있다면 외삽값을 실측과 대조해 보정한다.

## 학습 가이드

### 핵심 개념 — 이 챕터를 마치면 설명할 수 있어야 하는 것

- **리텐션 커브** — 코호트의 D+n 잔존율을 n에 대해 그린 곡선. DAU는 과거 코호트들의 커브 합.
- **power law 감쇠** — `y = a·x^b` (b<0). 지수 감쇠와 달리 꼬리가 두꺼워 앱 리텐션에 잘 맞는다.
- **모양 계수 `b`** — 커브가 얼마나 빨리 꺾이는지. `a`(시작점≈D1)와 분리된 "습관화" 지표.
- **상수로 접기** — `1 + Σ x^b`. 커브 전체를 "신규 1명이 1년간 만드는 활동일수" 배수 하나로 요약.
- **외삽의 한계** — 28일 관측으로 365일을 추정하는 것이므로 모델 가정이 곧 리스크.

### 개념 체크

1. `b`가 -0.3인 서비스와 -0.6인 서비스 중 어느 쪽의 상수(장기 DAU 배수)가 큰가? 왜?
   - 힌트: -0.3. `x^b`는 b가 0에 가까울수록 천천히 감소 → 누적합이 커진다.
2. 공식에서 D1 리텐션과 상수를 분리한 이유는?
   - 힌트: D1은 온보딩 개선으로, 커브 모양(b)은 습관 형성 기능으로 움직인다 — 액션이 다르다.
3. 이 공식의 DAU 기여가 실제보다 과대평가되기 쉬운 경우는?
   - 힌트: 캠페인 유입처럼 코호트 품질이 평소보다 낮을 때(적합에 쓴 코호트와 다른 b), 또는
     커브가 power law보다 빨리 꺾이는 경우.
