## 이 방법이 푸는 문제

유저 lifetime(가입 후 이탈 전까지 평균 활동일수)을 초기 7일 리텐션만으로 추정한다.
서로 다른 가정을 가진 세 방법을 같은 코호트에 적용해 결과를 교차 검증(삼각측량)한다:

- **실습 1 (Case 1). 이탈률 휴리스틱** — D1~D7 면적 + D7 이후 등비급수 꼬리 (`d7*r/(1-r)`).
- **실습 2 (Case 2). 리텐션 카탈로그 매칭** — 멱함수(`D_t = D1·t^(-b)`) 곡선 3,456장 중 (D1, D3, D7) SSE 최소 곡선의 lifetime.
- **실습 3 (Case 3). 장기 코호트 직접 측정** — 1년 전 코호트의 실측 lifetime을 두 코호트의 7일 면적 비율로 리스케일.
- **실습 4. 세 방법 결과 비교** — 세 추정치를 한 표·막대그래프로 나란히 놓고 삼각측량으로 읽는다.

노트북 헤딩은 `실습 1~4`이며, 이 문서의 `Case 1/2/3`은 각각 `실습 1/2/3`을 가리킨다
(실습 2 소절: 2.1 카탈로그 생성 → 2.2 시각화 → 2.3 SSE 매칭 → 2.4 해석 / 실습 3: 3.1 면적 비율 보정 → 3.2 해석 /
실습 4: 비교 표·그래프 → 4.3 마무리).

**책 이론부 포인터** — 자세한 설명은 책에서 읽게 안내한다.

- 1절: lifetime 정의 — 달력 기간이 아니라 **활동한 날의 합** = `ΣD_k` = 리텐션 곡선 아래 면적(그림1).
  1년(365일)에서 끊는 이유 3가지(CAC 회수 기간 6~12개월, 시간가치·할인율, 장기 추정 불확실성).
  꼬리가 두꺼운 습관형 서비스는 기간을 늘리거나 보정.
- 2절: 광고 기반 서비스에서 **LTV ≈ lifetime × ARPDAU** — lifetime이 CAC 상한선을 정한다
  (예: 50일 × $0.015 = $0.75). 커머스는 lifetime보다 구매 빈도·객단가가 중요.
- 3절: 정확도·속도 트레이드오프 — 1년 실측은 너무 늦고 1~2일은 노이즈가 커서, 실무 절충점이 **7일**.
- 4.1절: 이탈률 휴리스틱 — 일간 잔존비율 r(어제 대비 오늘 남는 비율)과 리텐션(곡선 높이)의 차이(그림2),
  등비급수 공식, 강점(한 줄 SQL·재현성·베이스라인)/약점(r 민감도, 두꺼운 꼬리 과소추정).
- 4.2절: 리텐션 카탈로그 매칭 — (D1 anchor, b) 격자로 멱함수 곡선을 미리 그려 두고(그림3, 표1)
  D1·D3·D7의 SSE 최소 행을 고른다. 세 점의 역할(D1 절벽 깊이, D3 초반 감속 곡률, D7 중기 안정화).
  강점(즉시 결과·재현성·외삽 생략)/약점(카탈로그 범위, 단일 시점 노이즈, 초기 구축 비용).
- 4.3절: 장기 코호트 직접 측정 — 1년 전 코호트의 실측 lifetime에 D1~D7 면적 비율을 곱해 보정.
  강점(현실성·설득력·안정성)/약점(1년 이상 데이터 필요, 구조적 변화·장기 꼬리 변화 미반영).
- 5절: 세 방법 비교 한 줄 — 휴리스틱은 빠른 하한선, 카탈로그는 자동화·일관성, 장기 코호트는 서비스 고유의
  결 반영. 신규 서비스 → 휴리스틱, 안정화 → 카탈로그, 1년 후 → 장기 코호트를 함께 돌려 교차 검증.
  5.1절은 lifetime 추정이 바꾸는 의사결정 4가지(CAC 가이드라인, 상충 실험의 통합 평가, 개선 성과의 조기 평가,
  채널·코호트 질 비교). 정리하며: D30·D90 실측이 쌓일 때마다 **재추정(Re-estimation)**.

## 함정

- 7일 관측으로 장기를 추정하므로, 제품 대격변(온보딩 개편 등) 직후 코호트에는 과거 기반
  Case 3 보정이 어긋날 수 있다. Case 3는 1년 이상 운영 데이터가 있어야 하고, D7 이후 꼬리 모양이
  과거와 달라진 변화까지는 잡지 못한다.
- lifetime은 "평균 활동일수"다 — 달력 기준 생존 기간과 혼동하지 말 것.
- Case 1은 `1/(1−r)` 때문에 r의 미세한 오차에 추정치가 크게 흔들리고(0.98→49배, 0.99→99배),
  두꺼운 꼬리를 표현하지 못해 구조적으로 과소 추정한다 — 하한선·베이스라인으로 쓴다.
- Case 2는 카탈로그 범위가 곧 모델의 한계다 — 독자 리텐션이 격자 밖이면 가장 가까운 행을 골라도 오차가
  남는다. D1·D3·D7 한 점이 주말·마케팅 이벤트에 걸리면 그 하루가 결과에 그대로 반영되므로, 하루치보다
  일주일치 가입자를 한 코호트로 묶어 재는 편이 좋다.
- 커머스처럼 매출이 활동 기간과 무관한 서비스에서는 lifetime 자체의 의미가 약하다(구매 빈도·객단가가
  더 중요). 광고 기반 서비스에서 가장 힘을 발휘한다.
- 단일 추정치를 절대 진리로 과신하지 말 것 — 가정이 다른 두 방법 이상을 항상 교차 비교한다.

## 학습 가이드

### 핵심 개념 — 이 챕터를 마치면 설명할 수 있어야 하는 것

- **lifetime** — 리텐션 커브 아래 면적(활동일수 기대값). `Σ retention(d)`. 달력 기간이 아니라 활동한 날의
  합이며, 실무에서는 1년(365일)까지 합산한다.
- **등비급수 꼬리** — "매일 남은 유저의 일정 비율(일간 잔존비율 r = 어제 대비 오늘 남는 비율)이 남는다"는
  가정으로 D7 이후를 `d7·r/(1−r)`로 접는 것. r은 리텐션(곡선 높이)과 다른 값이다.
- **멱함수 리텐션 (Power-law)** — `D_t = D1·t^(-b)`. 어제 대비 오늘 남는 비율이 `(t/(t+1))^b`로
  매일 1에 가까워지는 가정이라, 꼬리가 등비보다 두껍다. b가 클수록 가파르게 떨어진다.
  (sBG·Weibull은 파라미터가 둘인 대안이며, sBG의 장기 꼬리도 멱함수 꼴로 근사된다.)
- **카탈로그 매칭** — 모델을 직접 적합하는 대신, 미리 만든 곡선 사전에서 관측과 가장 닮은
  곡선을 찾는 근사법.
- **삼각측량** — 가정이 다른 추정을 교차시켜, 값이 아니라 **가정의 성립 여부**를 검증하는 태도.

### 개념 체크

1. 세 방법(Case 1 휴리스틱, Case 2 멱함수 카탈로그 매칭, Case 3 장기 코호트 보정)은 각각 어떤 가정에
   의존하나요?
   - 힌트: Case 1 = D7 이후 일간 잔존비율 r이 일정(등비급수), Case 2 = 리텐션이 멱함수 곡선족 안에 있음,
     Case 3 = 과거·현재 코호트의 커브 모양 상사성(7일 면적비가 1년 면적비와 같다).
2. 두 서비스의 D1 리텐션이 똑같이 34%인데, lifetime은 2배 차이가 날 수 있습니다. 왜 그럴까요?
   - 힌트: 꼬리 — 같은 시작점이라도 감쇠 속도(커브 모양, 멱함수의 b)가 다르면 면적이 크게 달라진다.
3. 삼각측량에서 세 값이 벌어졌을 때 "평균 내서 쓴다"가 왜 나쁜가?
   - 힌트: 벌어짐은 어떤 가정이 깨졌다는 신호다 — 평균은 신호를 지우고 틀린 값들을 섞는다. 예시 챕터에서는
     가정이 다른 Case 2·3이 만난 값을 신뢰하고 Case 1을 의심하는 것이 답이다.
4. 등비급수(r 고정)와 멱함수(r이 1로 수렴) 중 실제 앱 리텐션 꼬리를 더 잘 맞추는 쪽은? 그래서 휴리스틱은
   lifetime을 어느 방향으로 틀리는가?
   - 힌트: 멱함수 — 이탈 성향이 낮은 유저만 남아가며 실효 이탈률이 점점 떨어진다(log-log 축에서 직선).
     고정 r은 이 두꺼운 꼬리를 못 담아 과소 추정.
5. 카탈로그 매칭에서 D1~D7 전부가 아니라 D1·D3·D7 세 점만 쓰는데, 각 점은 곡선의 무엇을 재는가?
   - 힌트: D1 = 첫날 이탈 절벽의 깊이, D3 = 초반 감속 곡률, D7 = 중기 안정화 경향. 계산을 단순하게 유지하면서
     모양을 충분히 식별한다.
