argument-hint: [챕터명 또는 키워드]
---

data-analysis-101 스킬을 로드해 **내 데이터에 적용** 모드로 진행하라.

입력: "$ARGUMENTS"

- 입력을 챕터명·키워드로 해석해 스킬의 라우팅 표에서 챕터를 찾는다.
  애매하면 후보를 보여주고 독자가 고르게 한다. 입력에 데이터 설명이 섞여
  있으면(예: "우리 결제 로그로 MRR 분해") 챕터 매칭 후 인테이크에 활용한다.
- 입력이 없으면 어떤 방법을 어떤 데이터에 적용하고 싶은지 물어 챕터를 정한다.
- 챕터가 정해지면 해당 reference 파일의 인터랙티브 프로토콜 5단계
  (① 인테이크 → ② 데이터 점검 → ③ 코드 치환 → ④ 단계별 진행 → ⑤ 해석)를
  그대로 따른다. 데이터 점검을 통과하기 전에는 분석을 시작하지 않는다.
