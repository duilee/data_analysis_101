argument-hint: [챕터명 또는 키워드]
---

data-analysis-101 스킬을 로드해 **실행·검증** 모드로 진행하라.

입력: "$ARGUMENTS"

- 입력을 챕터명·키워드로 해석해 스킬의 라우팅 표에서 챕터를 찾는다
  (예: "lifetime", "라이프타임", "LTV" → `일주일_데이터로_Lifetime을_예측하라구요`).
  애매하면 후보를 보여주고 독자가 고르게 한다.
- 입력이 없으면 챕터 목록을 보여주고 어떤 챕터를 실행할지 물어본다.
- 챕터가 정해지면 해당 reference 파일을 읽고 스킬의 실행·검증 5단계 flow
  (① 예고 → ② 일괄 실행 → ③ 단계별 워크스루 → ④ 검증 판정 → ⑤ 마무리 안내)를
  그대로 따른다.
