# P값이 0.049면 출시해도 되죠?

이 챕터의 실습 코드입니다. A/B 테스트를 진행하는 방법이 아니라, **A/B 테스트 결과가 우리를
속이는 함정들**을 정답(진짜 효과)을 심어 둔 시뮬레이션으로 직접 눈으로 확인하는 실습입니다.
통계적인 디테일을 몰라도 가볍게 진행할 수 있게 구성했습니다.

- **실습 1.** 동전 던지기 — 아무것도 바꾸지 않아도 숫자는 출렁인다 (우연의 출렁임 워밍업)
- **실습 2.** 며칠 돌려야 하나요 — 표본 크기 계산기의 원리 (MDE별 필요 표본·기간)
- **실습 3.** 무작위로 나눴는데 왜 안 공평하죠 — 여행 임박 유저의 우연한 쏠림과 층화 배정
- **실습 4.** 3일째, 대시보드에 p = 0.04 — Peeking이 가짜 승리를 키우는 과정

## 실행 방법

```bash
jupyter notebook ab_test_pitfalls.ipynb   # 노트북을 위에서 아래로 실행 (첫 셀이 의존성 설치)
```

> 이 챕터는 **데이터 파일이 없습니다.** 전환율의 '진짜 값'을 코드에 정해 두고 실험 자체를
> 시뮬레이션하므로, 효과가 0인 걸 아는 상태에서 실험이 어떻게 우리를 속이는지 관찰할 수 있습니다.
> 시각화 라벨은 영어, 서술은 한국어이며 `np.random.seed(42)` 로 재현됩니다.
