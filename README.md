## 🤖 Claude Code로 실습하기

이 저장소에는 [Claude Code](https://claude.com/claude-code)용 스킬(`.claude/skills/da101/`)이 포함되어 있습니다.
저장소를 클론한 폴더에서 Claude Code를 열면 자동으로 인식되며, 이렇게 활용할 수 있습니다.

- **챕터 실행·검증** — "MRR 챕터 실행해줘", "노트북이 에러나요"
- **내 데이터에 적용** — "우리 서비스 결제 로그로 MRR 분해해줘"
- **방법 선택** — "DAU가 정체인데 뭐부터 봐야 할까?"
- **QnA** — "GRR이랑 NRR 차이가 뭐야?"
- **심화학습·퀴즈** — "이 챕터 이해했는지 확인해줘"

자연어 대신 `/da101` 슬래시 커맨드로 시작할 수도 있습니다. 첫 인자로 모드를 고르고,
나머지에 챕터명·키워드·질문을 적습니다:

| 사용 예 | 하는 일 |
| --- | --- |
| `/da101 DAU가 정체인데 뭐부터 봐야 할까` | 비즈니스 질문으로 알맞은 챕터 찾기 |
| `/da101 run mrr` | 챕터 노트북 실행·검증 (단계별 워크스루) |
| `/da101 apply 우리 결제 로그로 MRR 분해` | 챕터의 방법을 내 데이터에 적용 |
| `/da101 qna GRR이랑 NRR 차이` | 궁금한 개념 바로 답변 (QnA) |
| `/da101 quiz lifetime` | 심화학습·퀴즈로 이해도 확인 |

인자 없이 실행하면 챕터 목록과 5가지 모드를 보여주고 골라줍니다.

책과 무관한 자신의 프로젝트 폴더에서 쓰려면 `.claude/skills/da101/`을
`~/.claude/skills/`로 복사하세요.
